# 使用要求

## 宿主与文件

- 使用官方 DeepSeek Harness 客户端，在「设置 → Mojobox」操作。安装器不设置 DSH 版本号门槛，加载取决于宿主实际接口。
- 接受 Mojobox 薄 Feature Pack v1（`.dshpack`／ZIP），仅含根 `pack.json` 和可选根 `icon.png`。
- 归档上限 2 MiB，清单上限 1 MiB，图标上限 512 KiB。
- 插件使用可核验身份与精确版本的 npm bundle；下载与依赖解析需要联网，构建脚本审批按官版提示处理。
- `github:` 引用和无法确认映射的 `builtin:` 引用会显示单项不支持原因；不接管未知来源或非托管本地链接。

## 安装与更新

预览时可选择安装或更新的组件。同版本复用，已有高版本保留，不自动降级；更新不先删除旧插件，并核对配置变化。

整合包或插件的内核范围缺失、不匹配时会提示，允许继续核验；官版宿主仍执行插件自身的兼容检查。明确冲突、身份或摘要不符会阻止相关安装；普通单项失败后独立组件可继续执行。

删除仅针对用户确认的单个组件，操作前展示受影响的整合包，不清理插件私有数据。测试与恢复初态见[开发文档](development.md#客户端联调与提交)。
